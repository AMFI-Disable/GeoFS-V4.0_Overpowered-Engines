# Security Policy

## Supported Versions

Security fixes are intended for the latest version of this experimental project.

## Reporting A Vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting or email [evengao6688@gmail.com](mailto:evengao6688@gmail.com). Include reproduction steps and browser and script versions; do not send credentials or secrets.

## Response Timeline

Reports will be reviewed as maintainer availability permits.
